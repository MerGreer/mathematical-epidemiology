Activity 10.8.

The Python code in this activity is largely similar to the Python code in Activity 10.7. One notable difference is that the code in this activity involves the SEIR model rather than the SIR model, so we focus on the differential equations
\begin{align*} \frac{dS}{dt} \amp = -\beta S I \\ \frac{dE}{dt} \amp = \beta S I - \kappa E \\ \frac{dI}{dt} \amp = \kappa E - \gamma I \\ \frac{dR}{dt} \amp = \gamma I \text{.} \end{align*}
Another important difference is the newly added differential equation
\begin{equation*} \frac{dC}{dt} = \kappa E \end{equation*}
which keeps count of the population newly entering the Infectious compartment. We consider these to be the new cases, in this activity, as people typically become contagious with influenza approximately at the time they begin to show symptoms, and our dataset counts new infections at the time when symptoms become apparent. It is important to note that we are not introducing a new compartment “C” to the model when writing the \(dC/dt\) equation, but instead are developing a new differential equation solely to allow us to count new cases.
