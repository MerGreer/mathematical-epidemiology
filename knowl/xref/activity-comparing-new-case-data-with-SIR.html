Answer.
  1. The term \(\beta SI\) represents new infections, so this is the term we will use to count new cases.
    🔗
    🔗
  2. Summaries should refer to initial conditions, the system of differential equations, and derivatives, which are rates of change. The summaries may also refer to a step-by-step approach through time.
    🔗
    🔗
    • The for loop starts at Day 0, setting the model value for New Cases equal to 0.
      🔗
      🔗
    • For each day of our model simulation, we initially set the modeled number of new cases equal to 0. This happens in line 45.
      🔗
      🔗
    • Our timesteps are 0.1, so there are 10 of them per 1 unit of time. Lines 46 and 47 say that for each of these 10 timesteps (seen as range(0,10) in line 46), we compute \(\beta SI\) (more detail on this is below) and add together all these \(\beta SI\) values at every 0.1 step to compute the total value \(\beta SI\) across an entire day.
      🔗
      🔗
    • We compute \(\beta SI\) for each 0.1 timestep by subtracting: (\(S(t)\) at the current timestep) \(-\) (\(S(t)\) at the subsequent timestep). Remembering that \(dS/dt = -\beta SI\text{,}\) subtraction in this order results in the model’s value of \(\beta SI\text{.}\) If we subtracted in the opposite order, we would be computing the model’s value of \(-\beta SI\text{.}\)
      🔗
      To see that this is what we are computing, remember that sol stores all the numbers computed by Python for \(S(t)\text{,}\) \(I(t)\text{,}\) and \(R(t)\) values. To see these values, uncomment print(sol) in line 39 of the Python code and evaluate the code. The first row of sol is at time 0, and Python calls this row 0. The next row of sol is at time 0.1, and Python calls this row 1. And so on, through all the rows. The code sol[day * 10 + timestep, 0] calls for the element of sol appearing in row day * 10 + timestep, where day and timestep are determined by the for loop. The 0 at the end of sol[day * 10 + timestep, 0] means column 0, which holds the \(S(t)\) values produced by the model at each timestep.
